# IAMAIHM AI Assistant

IAMAIHM is a fully functional, single-file AI assistant that you can run anywhere. It features voice interaction, image recognition (Vision), code highlighting, and more.

## How to use the app

Since the entire app is contained in just one file (`index.html`), it is very easy to use!

### 1. Run it locally
1. Find the `index.html` file in this folder.
2. **Double-click** the file to open it in your web browser (Chrome, Safari, or Edge recommended).
3. Follow the onboarding instructions to enter your name and **OpenRouter API Key**.

### 2. Publish it online (Free)
You can make your app accessible from anywhere by using a free hosting service:

*   **GitHub Pages:** Upload this folder to a GitHub repository, go to **Settings > Pages**, and select your main branch.
*   **Netlify / Vercel:** Simply drag and drop the `index.html` file into their "Deploy" area.
*   **Tiiny.host:** A very simple "drag and drop" service for single HTML files.

## Features
- 🤖 **Multiple AI Models:** Choose between GPT-4, Claude 3.5, Gemini, and more via Settings.
- 👁️ **Vision:** Attach images to your messages for the AI to analyze.
- 🎙️ **Voice Call:** Click the phone icon to start a hands-free voice conversation.
- 💾 **Memory:** The app remembers your name and past topics. You can also export/import your memory.
- 📱 **PWA Ready:** On mobile, you can "Add to Home Screen" to use it like a real app.
